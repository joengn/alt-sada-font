# Sa Đà — Trial

**Sa Đà** is a condensed, high-contrast display typeface of capitals by Joe Nguyen · Studio Alt,
inspired by the cover of *The Little Prince*, 1966 edition by Khai Tri Bookstore.
Drawn for posters and headlines, with complete Vietnamese.

**[⬇ Download the free trial (ZIP)](https://github.com/joengn/alt-sada-font/releases/latest/download/AltSADATrial.zip)** · [Preview the typeface](https://fonts.studioalt.work/sada/)

## What's inside

| File | |
|---|---|
| `Fonts/OTF/AltSADATrials-RegularCHC.otf` | Static font. Recommended for macOS and design apps. |
| `Fonts/TTF/AltSADATrials-RegularCHC.ttf` | Static font, TrueType outlines. |
| `Fonts/Variable/AltSADATrialsVF-RegularCHC.ttf` | Variable font with a Width axis. |
| `EULA-Trial.txt` | Trial licence — please read before use. |
| `FONTLOG.txt` | Font details and version history. |

Install **either** the OTF **or** the TTF, not both (they share the same name).
The variable font has its own name and can be installed alongside them.

## Features

- A–Z, 0–9, basic punctuation and complete Vietnamese (all tone marks, Đ). Lowercase types as capitals.
- Width axis: `100` Regular · `125` SemiExpanded · `150` Expanded · `181.8` Golden. Cap height stays the same at every width.
- Tabular figures for prices, scores and timetables (Figma: Details › Numbers › Tabular; CSS: `font-variant-numeric: tabular-nums`).
- Best at display sizes — capitals 32 px tall or more, around −20 tracking for tight poster setting.

## Installing

- **macOS:** double-click the font, then **Install Font**. Remove older versions first.
- **Windows:** right-click the font, then **Install**.
- Restart your design apps afterwards.
